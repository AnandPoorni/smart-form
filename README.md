# Smart Registration Form

## Project Description
The Smart Registration Form is a simple student registration website created using HTML, CSS, and JavaScript. It allows users to enter student details and display them in a table.

## Technologies Used
- HTML – To create the registration form and student details table.
- CSS – To design and style the webpage.
- JavaScript – To add student details, display records, and delete records.

## Features
- Student name input
- Age input
- Gender selection
- Course selection
- Email address input
- Register student details
- Display registered students in a table
- Delete individual student records
- Success messages after registration and deletion
- Responsive design for mobile screens

## How to Run the Project
1. Download or clone the project.
2. Open the project folder.
3. Open the `index.html` file in your browser.
4. Enter student details and click **Register Student**.

## Project Functionality
When a user submits the form, JavaScript collects the entered details and displays them in a table. Users can also delete individual student records using the Delete button.

**Note:** Student records are displayed temporarily and will disappear when the page is refreshed because this project does not use a database or permanent storage.

## Conclusion
This project helps beginners understand HTML forms, CSS styling, JavaScript DOM manipulation, event handling, and dynamic table creation.
